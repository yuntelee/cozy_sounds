# Cozy Sounds

<img width="480" height="492" alt="snippet of game" src="https://github.com/user-attachments/assets/e00194f7-0480-4bc3-9a87-87329958d875" />

An interactive ambient soundscape controller built with an ESP32, physical controls, and a retro 2D pixel-art map built in React.

## Quick Start

Flash the ESP32 firmware ("esp32.ino"). The ESP32 has 3 physical components attached, a button, potentiometer, and a joystick.

Wire them as below.

<img width="1288" height="783" alt="breadboard diagram" src="https://github.com/user-attachments/assets/61b7f43a-f97b-4fb5-bf41-142fcb172a96" />

Once in the environment with the codebase, run in the terminal "npm install" followed by "npm run".

The game will start running in the browser. Once connected to the ESP32, your browser will prompt you or click the plug button on the bottom right of the game to connect to your ESP32. You will now be able to control the game with your hardware.
